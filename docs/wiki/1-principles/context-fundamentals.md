# 1. Context 是什么：模型当前能够依据哪些信息作答

> 状态：结构稿，正文待完善。

## 概要

说明一次模型请求的 Context 如何由指令、对话、工具结果和已读取材料组成，建立“文件存在于仓库”与“文件内容已进入本次上下文”的区别。区分模型参数中的知识、当前请求中的信息和宿主维护的外部存储，为后续讨论信息丢失与恢复建立基础。

## 正文规划

- Context、token 和 Context Window 的基本含义；输入与输出预算的具体关系按模型说明。
- 从用户消息、文件读取到工具结果，展示信息进入一次模型请求的路径。
- 区分模型、Agent 宿主和文件存储各自承担的职责；会话信息是否重送由宿主决定。
- 说明不同模型、宿主的实现差异，避免将一种宿主行为视为通用原理。

## 例子与依据准备

用同一条需求分别保存在聊天、仓库文件和读取结果中的例子解释“可存取”与“已可用”。正文补充模型官方 API 与宿主文档依据。
