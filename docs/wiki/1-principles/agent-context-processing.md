# 3. Agent 如何组织 Context：读取、行动、压缩与恢复

> 状态：结构稿，正文待完善。

## 概要

解释 Agent 宿主围绕模型形成的工作循环：选择工具、读取文件、接收结果、采取行动，再构造下一次请求。把自动压缩、截断、会话恢复和子代理交接放在这个循环中，说明上下文管理既包含模型能力，也依赖宿主策略。

## 正文规划

- 一次“读文件—修改—验证”如何改变后续请求中的信息。
- 区分未读取、被截断、被压缩遗漏与已读取但未正确使用。
- 压缩保存摘要时为何需要选择信息；文件持久化后为何仍需加载与核对。
- 新会话、恢复会话和子代理的输入如何由宿主或调度者提供。

## 例子与依据准备

正文核对宿主官方文档，以明确示意循环与特定产品实现的区别。
