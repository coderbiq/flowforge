# 06. 执行与协作：角色、上下文、模型和宿主

> 状态：重组后的结构稿，正文待完善。

## 概要

围绕“如何把有界工作交给合适的执行者”，解释新上下文、角色分工、调度交接、模型配置及多宿主部署。模型与环境配置作为执行机制的一部分，不另拆成孤立功能。

## 正文规划

### 1. 每次执行从哪些材料开始

说明一票一个上下文的约定、必读入口、明确输出和会话 handoff；新上下文不天然继承全部历史。

### 2. 角色分工与停止条件

解释分析、设计、实施和审查的边界，主会话保留的决定，轻量执行与完整模式，以及发现事实或设计冲突后的返回路径。

### 3. 并行与工作区隔离

区分 DAG 可并行、实际派发策略、文件冲突和隔离要求；按宿主真实能力描述，不把批次自动等同于并行。

### 4. 模型如何按工作需要配置

说明角色与模型选择、model/effort、model-set 的作用；准备和审查成本一并评价，不承诺更便宜一定更好。

### 5. 同一方法如何部署到不同环境

解释 Skill/角色资产、宿主原生格式、本机配置、漂移检查及权限保护边界；命令细节链接现有 CLI 文档。

## 内容边界

本文负责派发、运行环境和结果交接接口；证据内容、失败处置及审查闭环归入第07篇。

## 依据准备

核对角色定义、项目执行单元策略、宿主部署与模型配置实现，以及 [CLI 文档](../cli-design.md)。
