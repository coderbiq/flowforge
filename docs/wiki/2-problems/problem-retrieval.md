# 6. 信息已经落盘，为什么执行时仍会漏用

> 状态：结构稿，正文待完善。

## 概要

讨论文档保存与任务使用之间的距离：Agent 必须定位、筛选、解释并组合分散信息。长文档和明确任务之间缺少联系时，检索本身成为新的决策负担。

## 正文规划

- 查找位置、识别适用范围、组合约束分别有什么困难。
- 需求、设计、代码与历史证据之间如何出现冲突。
- 比较目录导航、语义检索和任务内摘要各自能解决的部分。
- 把“无法保证每次找全”与“Agent 无法检索”区分开。
