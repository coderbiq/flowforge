# 11. 为什么需要 Skill、Markdown 与 CLI 共同工作

> 状态：结构稿，正文待完善。

## 概要

解释语义判断、持久内容和确定计算的职责：Skill 指导人与 Agent 做分析和准备，Markdown 保存结论与证据，CLI 根据声明检查关系和计算队列。让读者理解机制组合的原因与能力边界。

## 正文规划

- 哪些工作需要理解业务，哪些适合由程序重复计算。
- Skill 约定、宿主强制机制与 CLI 校验的区别。
- 正文、元数据、链接各自承载什么。
- check 通过为何不能推出语义完整或交付正确；如何处理简单需求的流程成本。
