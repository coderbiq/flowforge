# 21. 外部材料接入：从旧文档中识别仍然有效的信息

> 状态：结构稿，正文待完善。

## 概要

解释旧 PRD、历史提案、笔记和外部请求如何进入新的分析设计。围绕材料中事实、候选要求、既有决定、证据与冲突混杂的问题，说明分类、来源定位与后续确认的作用。

## 正文规划

- 问题：把旧文本直接复制到新文档会把历史与现行要求混在一起。
- 机制：import 分类候选内容并保留出处，交由需求或设计责任方确认；triage 处理请求入口。
- 说明外部材料何时只是证据，何时转为已确认要求。
- 边界：分类与转写不自动产生业务认可，也不保证来源仍然有效。

核对 Import、Triage 及共享来源接入约定，给出一段混合旧材料的整理前后对比。
