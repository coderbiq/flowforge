# 20. 模型分工与执行边界：按工作需要配置能力

> 状态：结构稿，正文待完善。

## 概要

回答准备充分的任务如何支持分析、设计、执行和审查使用不同能力的模型。解释角色配置、轻量执行模式与升级返回条件。

## 正文规划

- 问题：同一模型承担所有环节的成本、配额和能力适配问题。
- 机制：前置决策与任务准备，执行有界动作，独立审查并允许阻塞返回。
- 区分角色定义、执行权限和模型能力。
- 边界：精准上下文不能消除能力差异，成本和质量需连同准备、审查、返工一起评估。

## 例子与依据准备
