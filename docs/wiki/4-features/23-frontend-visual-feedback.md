## 概要

解释代码、样式和文字描述为何不足以单独验证界面表现，以及截图如何把运行结果带入执行和审查。说明视觉实现循环与明确视觉条款的关系。

## 正文规划

- 问题：执行者可能未观察实际界面，审查缺少可核对结果。
- 机制：运行、截图、对照条款、自审修正和独立视觉复核。
- 区分图片观察、量化检查和主观设计取舍。
- 边界：截图覆盖有限状态，视觉模型判断与单次 PoC 不能构成普遍质量保证。
