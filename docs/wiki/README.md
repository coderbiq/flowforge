## 每部分如何避免重复

- **背景篇集中讲原因和困难。**Context、压缩、信息使用限制只在这里解释；功能篇不重新科普。
- **总览篇讲各机制如何协同。**以信息流与职责为主，细节通过链接交给功能篇。
- **功能篇把问题与解法放在一起。**简短点明当前问题，重点说明机制、输入输出、例子和边界，不再另设独立的问题篇。
- **一个概念只在一个主位置展开。**修订与引用在03篇，诊断对队列的影响在05篇；规范准备在04篇，执行结果是否合规在07篇。
- **不按 Skill 或 CLI 命令数量拆文档。**辅助能力归入其服务的工作；只有出现独立阅读需求时再考虑拆篇。
