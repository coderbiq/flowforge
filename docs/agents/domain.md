# Domain documentation

Durable domain authority lives under `<docs_dir>/` (default `docs/`):

- glossary and system invariants: `<docs_dir>/CONTEXT.md`;
- architectural decisions: `<docs_dir>/adr/NNNN-title.md`.

Read the relevant authority before changing governed concepts. Update `CONTEXT.md` only for durable vocabulary or invariants, and create an ADR only for a consequential decision with lasting alternatives. Feature requirements and solution details remain in `proposals/<feature>/`.
