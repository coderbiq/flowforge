# 复杂需求多代理分析编排

## Purpose

设计一套适用于复杂需求的低成本、多轮、可恢复分析编排机制。旗舰 Design Analyst 负责规划与综合，轻量 Coordinator 依据结构化计划调度调查角色，Proposal Artifact 与 Journal 共同保存可跨会话恢复的分析状态。

## Key Decisions

- Design Analyst 使用高能力模型并拥有分析规划、证据综合和设计判断权；Coordinator 使用轻量模型，只执行计划、管理用户交互和调用边界。
- 维持单层委托拓扑，所有 Subagent 均由 Coordinator 调用；Design Analyst 不递归委派。
- 角色按稳定职责和权限划分，调查来源由工具与动态 brief 决定，不为代码、Library、网络等来源分别增加角色。
- Agent 直接编辑 Proposal/FEATURE/FIND/DEC 正文；CLI 负责骨架、结构化事件、校验、stage、查询和派生索引。
- Markdown Artifact 与 JOURNAL.md 是事实源；SQLite 只保存可重建索引和运行态租约。
