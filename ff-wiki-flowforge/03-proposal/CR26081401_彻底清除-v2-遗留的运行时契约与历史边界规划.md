# 彻底清除 v2 遗留的运行时、契约与历史边界规划

## Purpose

规划在不改写、迁移或删除用户历史 wiki、旧 ID、旧 links 的前提下，彻底清除当前仓库可执行面中的 v2 遗留。范围包括运行时代码、测试契约与 fixture、当前 README/docs/Agent/部署资产，以及历史资料的明确保留和隔离规则；本 Proposal 只做设计、证据调查和实施分解。

## Entries

- [STR-CR26081401-REQ](../01-workspace/CR26081401_彻底清除-v2-遗留的运行时契约与历史边界规划/STR-CR26081401-REQ.md) (structure, active) - Requirement index

## Summary

### Objective

建立一套可执行的 v2 遗留清理边界：当前面必须从运行代码、测试契约、当前 Agent/部署资产和历史文档中去除 actionable v2 模型；历史面中的用户 wiki、旧 ID、旧 links 和既有历史记录保持原样，仅允许被标记、归档或明确列为不处理对象。

### Non-goals

- 本轮只更新 Proposal/FEATURE/DEC/Journal，不修改产品代码、测试、README、docs、assets、Agent/Skill 或 wiki，也不提交。
- 不改写、迁移、删除用户历史 wiki、旧 ID、旧 links、body 或 path；`STR-<proposal>-REQ` 保留为 Proposal control-plane metadata，不进入普通 Card 域。
- 不自动修复全库既有 25 条历史 wiki/library 断链；它们只作为隔离基线，除非后续有独立授权的历史资料 Proposal。

### Boundary Model

| 面 | 目标处理 | 允许的事实变化 |
|---|---|---|
| 当前运行时代码 | 删除不再属于 v3 当前契约的 v2 常量、解析/生成入口和 actionable 引用；确认历史文件解析是否必须保留 | 仅形成后续实施计划，不在本轮写代码 |
| 测试与 fixture | 删除或改写过时测试契约；隔离历史 fixture 的只读基线 | 仅规划测试写集，禁止删用户数据 |
| 当前文档/Agent/部署资产 | 清除当前可执行路由、过时开放问题和 v2 模型说明；历史参考需显式标记 | 仅形成文件级清单，不编辑这些文件 |
| 历史资料与 ff-wiki-flowforge | 只做保留/标记/归档/不处理分类；隔离断链基线 | 不迁移、不改写、不删除历史内容 |

### Decision Rule

每个残留必须回答四选一：删除（当前契约已废弃且无历史读取责任）、保留（仍承担历史文件读取/审计责任）、标记（仅作为历史资料可见但不可 actionable）、迁移（只允许进入未来独立 Proposal，需 dry-run、manifest、备份/回滚和显式确认）。没有证据时保持未知，不擅自选择迁移。
