# 运行时代码与历史解析边界清理规划

<!-- analysis-mode: complex -->

## Summary

删除当前运行时的 v2 解析、旧类型公开契约、task-specific 与旧 cross-reference 检查；保留 current-v3 生命周期门禁和 Proposal control-plane 的 STR 内部识别。

## Motivation

旧解析和旧公开 Prefix 规则会把历史文件形状继续暴露为 current-v3 契约；旧 task-specific/cross-reference 路由也会让已删除模型继续可执行。

## Objective

完成运行时代码清理计划，覆盖 `ParseCardID`、`ParseFilename`、旧 `CardType`/Prefix、task-specific、旧 `DES/REQ/TASK/STR` cross-reference、旧写入入口和 dead task-ID helper。

## Current Understanding

- FIND-CR26081401-006 已确认 `GenerateTaskID` 无生产调用，`NextTaskID` 已返回 unsupported。
- 用户已确认删除 `ParseCardID`，并将 `ParseFilename` 收窄为当前 v3 文件名格式。
- 用户已确认删除旧 CardType 常量、公开 Prefix 规则、task-specific 与旧 cross-reference 检查。
- `card_evolve` 的 FEATURE 阶段和 complex-analysis 门禁、Proposal control-plane STR loader 仍是当前契约。

## Evidence

Support state: accepted. FIND-CR26081401-006 提供运行时符号、调用者和历史责任矩阵；FIND-CR26081401-007 提供正向测试与边界 fixture 矩阵。用户决策已解除 DEC-010/011/012 门禁。

## Design

### Key Decisions

- `ParseCardID`、TASK/subtask 专属解析、旧 CardType 常量、公开 Prefix/FromPrefix 规则删除。
- `ParseFilename` 只接受当前 v3 `{ID}_{slug}.md` 文件名；旧文件原样保留但不再获得运行时解析兼容。
- 删除 task-specific 和旧 `DES/REQ/TASK/STR` cross-reference 检查；保留 FEATURE-only stage/complex-analysis gates。
- `STR-<proposal>-REQ` 只由 Proposal control-plane 内部 loader 识别，普通 CardStore/list/search/index 不识别 STR。

### Architecture

current-v3 card domain、Proposal control-plane metadata 和 historical read-only files 三域分离。旧文件不进入 current query/index；STR loader 只服务 Proposal inspect/traceability。

### Alternatives Considered

- 永久保留 `ParseCardID`：拒绝，用户已确认不设旧解析兼容窗口。
- 继续公开旧 CardType/Prefix：拒绝，旧类型不再是当前 API。
- 连同旧 cross-reference 一起删除 `card_evolve` 门禁：拒绝，会破坏 FEATURE 生命周期契约。

## Working Design

先由 FEAT-CR26081401-003 已完成的测试契约收敛作为前置；本 FEATURE 内先拆除旧 task/log/structure 写入、task-specific、proposal_report 旧健康逻辑和 validate 旧 cross-reference 的生产调用，再删除旧符号，最后集中验证 ParseFilename、current-v3 ID、STR control-plane、FEATURE 门禁和历史只读边界。

## Rejected or Revised Assumptions

- 不再假设历史文件需要运行时解析兼容。
- 不再假设公开 Prefix 是 current-v3 必需 API；current-v3 只保留必要的内部 ID 生成实现。
- 不再假设 `card_evolve` 的所有旧前缀检查都属于 FEATURE 门禁。

## Constraints

- 不修改 `ff-wiki-flowforge` 中任何用户历史 wiki、旧 ID、旧 links、body、frontmatter 或 path。
- 不删除 Proposal control-plane 的 STR 文件、写入和独立读取责任。
- 不把 STR control-plane 识别重新接入普通 CardStore、list、search 或 index。
- 不修改 README、docs、assets、AGENTS 或目标项目文件；这些由 FEAT-CR26081401-004 处理。
- 不在本 FEATURE 中新增兼容窗口、alias、fallback 或迁移写入。
