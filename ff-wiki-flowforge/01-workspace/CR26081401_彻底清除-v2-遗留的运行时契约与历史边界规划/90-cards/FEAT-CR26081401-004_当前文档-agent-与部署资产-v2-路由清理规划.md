# 当前文档 Agent 与部署资产 v2 路由清理规划

<!-- analysis-mode: complex -->

## Summary

删除当前 docs/assets 中仍可执行的 v2 路由和旧模板；一般背景资料标记 `historical`/不可执行；保留 v3 与必要历史说明；立即删除隐藏 `assets update` compatibility bridge。

## Motivation

当前 docs 和 deployable assets 会继续指导旧命令或旧卡模型，隐藏兼容桥还会保留未定义的旧客户端支持面；两者必须在 runtime/test 契约完成后收敛。

## Objective

完成 README/docs/AGENTS/assets 的 v2 actionable 路由清理计划，明确删除项、historical 保留项、v3 保留项、manifest/checksum 变化和用户目标文件保护。

## Current Understanding

- FIND-CR26081401-008 已确认 `assets/` 会部署到目标项目，旧模板和 STR/create 占位仍可影响 Agent。
- 用户已确认删除含可执行旧命令的过时 docs，一般背景资料标记 historical。
- 用户已确认删除 assets 旧 Requirement/Design/Task/Log/Structure 模板及 STR/create 占位，保留 v3/必要历史说明。
- 用户已确认立即移除 hidden `assets update` bridge，不设置兼容窗口。

## Evidence

Support state: accepted. FIND-CR26081401-008 提供 source-to-target 部署映射、旧路由清单和 sync/deploy 的 conflict/preserved 语义；DEC-013/014/015 已被用户确认。

## Design

### Key Decisions

- 当前可复制执行的旧命令从 docs/Agent 入口删除。
- 一般背景 docs 保留并显式标记 `historical`/不可执行，不进入当前 Skill 路由。
- assets 旧模板和 STR/create 占位删除；v3 模板和必要历史说明保留。
- hidden `assets update` bridge 立即删除，无旧客户端兼容窗口。
- deploy/sync 只更新批准的 FlowForge 管理区，冲突和用户自定义内容保持可见、保留且不被 `--adopt` 覆盖。

### Architecture

仓库当前入口、仓库历史背景和 deployable assets 分离；`docs/proposal-v3` 与 current FEATURE/card/Journal 是当前规范入口，`assets` 只通过 manifest/checksum 和 conflict/preserved 机制下发。

### Alternatives Considered

- 保留旧可执行 docs：拒绝，会继续产生错误 Agent 路由。
- 删除全部 docs/assets：拒绝，需要保留 v3 和必要历史说明。
- 保留 hidden bridge 等待未知客户端：拒绝，用户已明确无兼容窗口。

## Working Design

在 FEAT-CR26081401-003、FEAT-CR26081401-002 和 FEAT-CR26081401-005 完成后，先清理当前 docs 路由，再清理 deployable assets 和 bridge，最后运行 manifest/checksum、dry-run、conflict/preserved 和 current-v3 route smoke 验证。

## Rejected or Revised Assumptions

- 不再假设仓库内无引用即可删除 deployable assets。
- 不再假设所有含 v2 词汇的背景资料都应删除。
- 不再假设 hidden bridge 需要等待外部客户端确认。

## Constraints

- 不修改 `ff-wiki-flowforge` 中用户历史 wiki、旧 ID、旧 links、body、frontmatter 或 path。
- 不覆盖、接管、迁移或删除目标项目用户文件；不使用 `--adopt` 作为默认或自动路径。
- 不删除 `docs/proposal-v3`、v3 assets 或必要历史说明。
- 删除 bridge 不得通过 alias、回滚或旧客户端路径恢复兼容窗口。
- 本轮只修改 Proposal/FEATURE/DEC/Journal；不修改 docs/assets/AGENTS/代码/目标项目。
