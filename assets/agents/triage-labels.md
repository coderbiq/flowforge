# Triage labels and roles

When triaging issues, categorize into:
- `bug`: Something broken that worked before or violates expectations
- `enhancement`: New feature or improvement

State machine roles:
- `needs-triage`: Awaiting initial triage
- `needs-info`: Blocked on answers from the user
- `ready-for-agent`: Crisp behavior specification ready for an agent to build
- `ready-for-human`: Requires human action (credentials, external setup)
- `wontfix`: Out of scope or rejected
