# Logic prototype

Build one throwaway, shareable HTML file that makes a state model directly manipulable.

- Provide guided cases for the normal path and the hardest boundary cases.
- Provide free-play controls for every meaningful transition.
- Keep the complete derived state visible after each action.
- Record the question, observation, and verdict in the calling design authority; do not promote prototype code into production.

Completion means the selected design question has an observable answer across the cases that could falsify it.
