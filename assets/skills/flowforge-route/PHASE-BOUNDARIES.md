# Phase boundaries

- Align owns why, observable outcomes, scope, and requirement unknowns.
- Solution design owns responsibilities, interfaces, seams, flows, migration, and verification strategy.
- Plan owns independently verifiable increments and DAG edges.
- Implement owns production changes and completion evidence.
- Review independently checks standards and the effective specification.

Return work upstream when a downstream phase would have to make a decision owned by an earlier phase. This is a semantic handoff, not a persisted workflow state.
